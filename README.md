# FIFA World Cup 2026 Data Analysis Project

## Overview
This project provides an in-depth data analysis of the FIFA World Cup 2026. The dashboard delivers comprehensive insights into tournament statistics, team performances, and individual player metrics to help stakeholders understand the dynamics of the tournament.

## Dashboard Structure
The Power BI report is organized into four main sections:

1. **Home Page**: Acts as the project hub, summarizing the focus areas including host nations, match schedules, venues, and key historical statistics and insights.
2. **Overview**: Provides a high-level view of tournament metrics such as total goals (3,024), total matches (55k), player counts, and average ratings. It includes breakdowns of top scorers, best national teams, goals by position, and assists.
3. **Teams & Match Analysis**: Focuses on team-level performance, including offensive contributions, defensive activities (tackles, clearances, interceptions), disciplinary records (yellow/red cards), and offensive force metrics based on xG (Expected Goals) and xA (Expected Assists).
4. **Player Performance**: Delivers granular analysis of individual players, showcasing top scorers, top assists, xG vs. actual goals comparison, and a correlation analysis between marketing value and tournament evaluation.

## Key Features
*   **Interactive Filters**: Users can filter data by Team, Position, and Player Name to customize the analysis.
*   **Visualizations**: Utilizes bar charts, doughnut charts, scatter plots, and key performance indicators (KPIs) to present complex data clearly.
*   **Comprehensive Metrics**: Tracks critical KPIs like total goals, passes, defensive actions, pass accuracy, and marketing value.

## Tools & Technologies
*   **Power BI**: Used for data modeling, visualization, and dashboard creation.
*   **Data Analysis**: Performed using professional business intelligence techniques to derive actionable insights from tournament data.

## Project Goal
The primary objective of this project is to analyze the 2026 FIFA World Cup data to uncover trends and patterns that define team and player success on the global stage.
